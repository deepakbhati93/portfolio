# 📧 Contact Form

The portfolio includes an interactive contact form with:

* Name validation
* Email validation
* Message validation
* Loading state
* Success message
* Error message
* Backend API request

The JavaScript sends form data to a Netlify Function endpoint:

```text
/.netlify/functions/send
```

For local development, it uses:

```text
http://localhost:8888/.netlify/functions/send
```

## The form requires a valid name, email, and message of at least 10 characters before submission.
